# Claude Bubble

Плавающая кнопка поверх других приложений. По нажатию показывает использование лимитов Claude.ai за 5 часов и 7 дней (в процентах, число токенов Claude.ai не отдаёт).

## Сборка APK (GitHub Actions)
1. Создайте репозиторий на GitHub и загрузите в него все файлы проекта (включая папку `.github`).
2. Вкладка Actions → дождитесь сборки → скачайте артефакт `ClaudeBubble-apk`.
3. Установите `app-debug.apk` на телефон.

## Токен
На компьютере с Claude Code выполните `claude setup-token` и скопируйте выданный токен (`sk-ant-oat...`).
Либо поставьте Claude Code в Termux на телефоне и выполните ту же команду.

## Использование
1. Откройте приложение, вставьте токен, нажмите «Сохранить».
2. Выдайте разрешение «поверх других окон».
3. Нажмите «Показать плавающую кнопку». Нажатие на «C» показывает лимиты, кнопку можно перетаскивать.

Каждая проверка отправляет запрос на 1 токен. Способ неофициальный и может перестать работать.

## Чат с бесплатным LLM API
В главном окне есть кнопка «Чат с ИИ (бесплатный API)». Работает с любым OpenAI-совместимым API, готовые варианты с бесплатным тарифом:

| Провайдер | Модель по умолчанию | Где взять ключ |
|---|---|---|
| Groq | `llama-3.3-70b-versatile` | https://console.groq.com/keys |
| OpenRouter | `meta-llama/llama-3.3-70b-instruct:free` | https://openrouter.ai/keys |
| Google Gemini | `gemini-2.5-flash` | https://aistudio.google.com/apikey |

1. Откройте «Настройки API», выберите провайдера и нажмите «Получить бесплатный ключ».
2. Вставьте ключ и нажмите «Сохранить настройки».
3. Пишите сообщения. «✕» очищает историю диалога.

Модель и Base URL можно поменять вручную (пункт «Свой» — для любого другого совместимого сервиса). Бесплатные тарифы ограничены по числу запросов, а список бесплатных моделей у провайдеров иногда меняется.
