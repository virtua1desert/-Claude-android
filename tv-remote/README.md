# LG Пульт

Android-приложение: пульт для телевизоров LG на webOS (проверялось на дизайне OLED B1, webOS 6) по Wi-Fi/Ethernet.

- **Пульт** (версия 2.0): сверху две качалки (звук слева, каналы справа) и крестовина, как у Nintendo, с кнопками Назад / Дом / Меню по углам. В правом нижнем углу кнопка гироскопа: пока держите, телефон работает как указка. Ниже широкая кнопка OK (долгое нажатие открывает радиальное меню: Назад, Дом, Меню, Звук, Выход), а под ней тачпад на всю нижнюю часть.
- **Указка**: зажмите шар и водите телефоном, курсор на ТВ следует за гироскопом.
- **Текст**: набор текста с клавиатуры телефона в поле ввода на ТВ.
- **Плитки**: первой идёт HDRezka (открывает hdrezka.ag в браузере ТВ), дальше приложения самого ТВ.
- **Ещё**: скорость указки (ступенчатый слайдер), положение телефона, инверсия осей, выключение ТВ (нужно удерживать).

## Сборка APK
Вкладка **Actions** → «Build LG Remote APK» → артефакт `LGRemote-apk` → `app-debug.apk`.
Сборка запускается сама при изменениях в `tv-remote/`, либо вручную кнопкой *Run workflow*.

## Первый запуск
1. На ТВ: Настройки → Общие → Устройства → Внешние устройства → включить «Включение ТВ через мобильное устройство» (LG Connect Apps).
2. Телефон и ТВ в одной сети.
3. В приложении нажмите «Найти ТВ в сети» или введите IP, на ТВ нажмите «Да».

Приложение не устанавливает и не удаляет приложения на ТВ: LG запрещает это внешним устройствам.
